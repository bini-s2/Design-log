# 2026-11-13 — 사용성·휴리스틱 평가·UX 법칙 학습

`UX/UI` · `Usability` · `Heuristic Evaluation` · `UX Laws`

- **사용성:** 학습 용이성·효율성·기억 가능성·오류·만족도의 다섯 구성 요소를 구분하고, 사용자의 작업과 맥락에 따른 차이를 정리함.
- **평가 방법:** 정성·정량 리서치, 휴리스틱 평가, 사용성 테스트의 목적과 한계를 비교함. 휴리스틱에서 찾은 항목은 실제 사용자 행동으로 검증할 문제 후보로 구분함.
- **10가지 휴리스틱:** 시스템 피드백, 현실과의 일치, 통제와 자유, 일관성, 오류 예방, 기억보다 인식, 효율성, 미니멀한 디자인, 오류 복구, 도움말을 학습함.
- **UX 법칙:** 피츠·힉·제이콥·밀러의 법칙과 게슈탈트·근접 원리를 학습함. 밀러의 7±2를 UI 선택지 수의 고정 기준으로 사용하면 안 됨을 정리함.
- **문제 진단:** 막연한 인상 대신 화면 요소와 사용자의 예상 행동으로 문제를 구체화하고, 평가 범위 결정 → 개별 평가 → 취합 → 심각도 판단 → 개선안 도출 순서를 정리함.
- **심각도:** 빈도·영향·지속성을 참고하는 0~4점 평가 체계를 학습함. 실제 휴리스틱 평가나 사용자 테스트 수행 결과로 오인되지 않게 학습 내용만 기록함.
- **학습 글 작성:** 해당 주제를 바탕으로 게시용 TIL 초안을 작성했으며 블로그 발행은 별도로 진행하지 않음.
