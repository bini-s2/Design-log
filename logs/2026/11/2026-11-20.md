# 2026-11-20 — React·Figma Dev Mode·핸드오프 학습

`UX/UI` · `React` · `Figma Dev Mode` · `Handoff`

- **React 기초:** 컴포넌트·Props·State·렌더링의 역할을 구분하고, JSX를 JavaScript 안에서 UI 구조를 기술하는 문법으로 정리함. `count` 상태와 클릭 시 증가하는 버튼 예시를 통해 화면 갱신 흐름을 이해함.
- **디자인-개발 네이밍:** Figma 컴포넌트/Variant와 React 컴포넌트/Props의 대응 방식을 학습함. `Button`, `Card`, `variant="primary"` 등 명칭을 팀에서 합의할 필요가 있음을 정리함.
- **Dev Mode:** 개발자가 크기·간격·스타일·컴포넌트·변수·에셋·코드 스니펫을 확인하는 용도로 정리함. 디자인을 코드로 자동 완성하는 기능과는 구분함.
- **Ready for Dev:** 디자인을 개발에 전달할 준비가 되었음을 알리는 상태로 이해하고, 변경 시 재확인·공유가 필요함을 기록함.
- **핸드오프:** 기획 → 시안 공유와 개발 난이도 논의 → 전달 → 개발 중 질의/변경 대응 → 디자인 QA의 협업 흐름을 학습함. 네이밍·상태·인터랙션·반응형·예외 화면 정리의 중요성을 메모함.
- **디자인과 코드 연결:** Figma MCP 서버는 AI 코딩 도구에 구조화된 디자인 정보를 제공하고, Code Connect는 디자인 컴포넌트와 실제 코드 컴포넌트를 매핑함을 학습함. AI 화면 생성 결과도 검증이 필요함을 구분함.
- **TIL 초안 작성:** 학습 메모를 기존 TIL 양식에 맞춰 정돈하고 개념 설명을 보강함. **실제 구현·디자인 QA·블로그 발행 여부는 확인되지 않음.**
