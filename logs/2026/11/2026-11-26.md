## UX 원칙의 실무 활용

- UX 법칙과 10가지 사용성 휴리스틱을 실무 의사결정 및 평가에서 사용하는 표현으로 정리했다.
- 원칙의 명칭 암기보다 사용자 문제, 설계 이유, 개선 방향을 연결하는 방식에 초점을 맞췄다.
- 실제 개선 효과는 별도 사용성 테스트나 데이터로 검증해야 함을 확인했다.

## 프론트엔드 기초 용어

- HTML 태그와 속성을 카드, 입력 필드, 내비게이션 등의 UI 구조와 연결해 정리했다.
- CSS 스타일, 타이포그래피, 레이아웃, 반응형 단위, 인터랙션을 디자인 도구의 개념과 비교했다.
- JavaScript의 변수, 자료형, 함수, 이벤트, 조건문과 React의 컴포넌트, Props, State, 렌더링 개념을 학습 자료로 정리했다.
- 카드 예시를 통해 HTML은 구조, CSS는 표현, JavaScript는 동작을 담당한다는 차이를 정리했다.

## 학습 기록 작성

- 프론트엔드 기초 용어와 UX 원칙을 표 중심의 블로그 TIL 초안으로 구성했다.
- 디자인 도구와 코드의 대응 관계는 이해를 위한 비유이며, 실제 구현과 일대일로 일치하지 않음을 명시했다.
