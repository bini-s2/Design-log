# 2026-11-22 — Framer 갤러리 반응형·타이포그래피 작업

`Framer` · `Responsive Layout` · `Typography` · `Portfolio`

## 갤러리 레이아웃 개선

- 사진 아카이브 코드 컴포넌트의 데스크톱(1920/1440)·태블릿·모바일 레이아웃을 검토함. 고정 컬럼 너비로 인한 1440 기준 우측 텍스트 잘림 문제를 확인하고, 섹션 Fill·내부 콘텐츠 중앙 정렬·유동형 너비 방향으로 수정안을 요청함.
- 갤러리 콘텐츠 순서를 여러 차례 비교한 뒤 **이미지 → 캡션 → 본문 → PREV/진행 표시/NEXT 버튼**으로 정리함. 버튼은 가장 아래에 배치하고자 함.
- 캡션 스타일을 **14px / Regular(400) / Line Height 1.4 / Opacity 0.8**로 정의함.
- 섹션이 작아 보이는 문제와 요소 간 간격 불일치에 대응해 콘텐츠 최대 너비, 이미지 최대 너비, 최소 높이, 개별 Gap, 정렬을 Framer 패널에서 조정할 수 있는 코드 컴포넌트 버전 제공을 요청함.
- **검증 상태:** 수정 코드 파일은 대화에서 전달되었으나 Framer Preview의 모든 브레이크포인트에서 정상 반영되었는지는 확인되지 않음.

## 포트폴리오 카피·타이포그래피

- 사진 아카이브에서 사람의 열정과 우연히 마주한 풍경을 **디자인 에너지의 원천**으로 표현하는 카피를 검토함. '영감' 대신 '에너지'라는 표현을 선호하고 타이틀의 시각적 리듬을 고려함.
- 가져온 Framer 템플릿의 폰트가 혼재된 문제를 파악하고 폰트 교체 플러그인·AI 활용을 검토했으나, 공통 컴포넌트와 Text Styles를 우선 점검하며 **수동 정리**하는 방향을 선택함.
- **새로 배운 기능 — Fit Text:** Framer 텍스트 Size에서 **`100% / Fit`** 설정을 사용하면 컨테이너 너비를 기준으로 큰 타이틀의 글자 크기를 조절할 수 있음을 화면에서 확인함. 섹션 가득 채우는 반응형 타이포그래피에 활용할 수 있으며, 부모 너비와 작은 화면에서의 가독성은 별도 검수가 필요함.

## 다음 점검

- 1920·1440·태블릿·모바일에서 갤러리의 잘림, 정렬, 간격, 전환 버튼 동작을 Preview로 확인.
- Fit Text를 적용한 타이틀의 줄바꿈 및 작은 화면의 글자 크기 확인.
- 공통 Text Styles 기준으로 템플릿의 타이포그래피 수동 정리.
