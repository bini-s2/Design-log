# 2026-11-03 — 컴포넌트·Input UX 학습

`Figma` · `Component` · `Input` · `Mobile UX`

- **컴포넌트:** Opacity 미사용 메모(적용 맥락 확인 필요), 알림 배지가 왼쪽으로 확장되는 배치 규칙을 정리함.
- **Input:** 필수(`*`)·선택(`(선택)`) 표기와 Empty / Focus / Filled / Error / Disabled 상태를 학습함.
- **오류 안내:** 로그인 실패 시 잘못된 항목을 특정하면 계정 유효성 추정에 악용될 수 있어 일반적인 인증 실패 메시지를 사용하는 이유를 확인함.
- **모바일:** 키보드가 입력 필드와 버튼을 가리는지, 입력 목적에 맞는 키보드가 표시되는지 확인할 필요를 정리함.
