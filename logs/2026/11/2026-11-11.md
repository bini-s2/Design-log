# 2026-11-11 — UI 컴포넌트 네이밍·인터랙션 학습

`UX/UI` · `Component` · `Prototype` · `AI-assisted Design`

- **컴포넌트 분류:** 버튼·링크·토글·체크박스·라디오의 역할과 선택 방식, 아이콘 버튼의 충분한 터치 영역을 학습함.
- **입력과 탐색:** 라벨·플레이스홀더, 드롭다운·칩·스테퍼·슬라이더, 앱 바·탭 바·탭·세그먼트 컨트롤의 차이를 정리함.
- **안내와 콘텐츠:** 토스트·스낵바·배너·모달·바텀시트, 툴팁·코치마크, 로딩·진행 상태와 카드·리스트·캐러셀의 역할을 구분함.
- **인터랙티브 컴포넌트:** Variant 전환, 탭·호버 트리거, 반대 방향 상태 연결, 프로토타입 이동 경로와 레이어 순서를 확인해야 함을 정리함.
- **AI 레이어 네이밍:** 대상 범위를 선택하고 자동 생성된 이름을 검수·수정하는 절차를 학습함. 작업 시간 개선 효과는 측정하지 않음.
- **학습 글 초안:** 당일 필기를 바탕으로 공개 게시용 TIL 초안을 구성함. 실제 블로그 발행이나 사용자 테스트는 진행했다고 기록하지 않음.
