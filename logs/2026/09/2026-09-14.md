## 16:20 · Design Log 작업 기록 자동화 구축

`Automation` · `ChatGPT`

작업 기록을 별도 일처럼 느끼지 않도록 Design-log를 중앙 작업 저널로 정리하고, 대화 명령·GitHub 버튼·Tistory RSS 세 경로로 기록할 수 있는 구조를 만들었다.

### Notes

- `/log`, `기록해줘`, `깃허브에 남겨줘` 같은 명령으로 대화 맥락을 요약해 기록하는 규칙을 추가했다.
- GitHub Actions의 `Add Work Log`를 통해 대화 밖에서도 버튼으로 작업 기록을 추가할 수 있게 구성했다.
- Tistory 새 글은 RSS를 6시간마다 확인하고 새 글이 있을 때만 자동 기록하도록 구성했다.
- 자동 기록은 하루 한 파일에 모으고 README의 Recent Activity 인덱스를 자동 갱신하도록 했다.
- 공개 저장소이므로 디자인·학습·창작 작업만 기록하고 개인적인 대화와 민감 정보는 자동 기록하지 않도록 안전 기준을 명시했다.
