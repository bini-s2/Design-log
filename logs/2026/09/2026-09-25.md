## 일본어 소리 검색 — 구어체·문어체·J-POP 가사 검색 확장

`Search UX` · `Japanese Learning` · `Ranking` · `QA` · `AI-assisted Development`

한글로 기억한 일본어를 실제 표기와 뜻으로 연결하는 검색 기능의 커버리지를 넓히고, 검색 결과의 신뢰도를 높이기 위한 데이터·랭킹·검증 계층을 확장했다.

### 구어체 검색 확장
- 일상 회화, 축약형, 반응 표현, 거친 말투, 간사이 표현 등을 별도 구어체 사전으로 정리했다.
- 약 120개 이상의 고빈도 표현을 검색 데이터에 추가하고, 기존 핵심 표현과 중복되지 않도록 병합했다.
- `〜ちゃう / 〜ちゃった / 〜なきゃ / 〜なくちゃ / 〜てる / 〜とく / 〜っていう / 〜じゃん / 〜だろ` 등 회화 문법 패턴을 일반 규칙으로 확장했다.

### 문어체·격식·문학 표현 확장
- 논문·기사·설명문·소설·가사에서 자주 등장하는 문어체 표현을 별도 데이터로 구성했다.
- 약 160개 이상의 문어·격식·문학 표현을 검색 데이터에 추가했다.
- `〜において / 〜に基づいて / 〜にもかかわらず / 〜ざるを得ない / 〜である / 〜とされる / 〜に至る` 등의 구조를 문장 검증 신호로 추가했다.
- 자동완성에 없더라도 상위 IME 변환, 발음 일치, 문어 구조를 통과하면 문장 후보로 유지할 수 있도록 검색 조건을 확장했다.

### 기본 단어 의미 정확도 개선
- 영영 사전의 다의어 gloss를 일반 영어 문장처럼 번역하면서 뜻이 틀어지는 문제를 확인했다.
- 짧은 기본 어휘는 일본어→한국어 의미를 우선하고, 영어 사전 gloss가 다의적인 경우 별도 정규화를 거치도록 수정했다.
- 대표 오류였던 `粉(こな)`가 ‘식사’가 아니라 ‘가루 / 분말’로 안정적으로 표시되도록 회귀 검증을 추가했다.

### J-POP 가사 검색 보조
- 전체 가사 원문을 저장하지 않고, 현재 인기곡·아티스트의 검색 메타데이터만 별도 신호로 구성했다.
- 일반 자동완성과 함께 `복원한 일본어 발음 + 歌詞` 검색 자동완성을 병행하도록 확장했다.
- 실제 가사 검색에서 자주 등장하는 후보와 현재 인기 J-POP 신호를 랭킹에 반영했다.
- 표현 뒤에 붙는 곡명·아티스트명·가사·의미 같은 검색 문맥은 제거하고, 학습할 일본어 표현 본문만 남기도록 처리했다.
- 일반 검색에는 잡히지 않지만 가사 검색에서 자주 등장하는 문장도 후보로 회수할 수 있도록 검색 경로를 추가했다.

### 품질 관리
- 구어체·문어체·기초 어휘·J-POP 검색 신호가 빠지거나 핵심 검색 정책이 깨지면 배포 전에 확인할 수 있도록 회귀 테스트 범위를 확장했다.
- 후보 수를 채우는 것보다 실제 사용 빈도, 발음 일치, 문법 구조, 의미 정확도, 검색 신뢰도를 우선하는 원칙을 유지했다.

### 정리

이번 작업에서는 검색 범위를 단어 중심에서 **구어체·문어체·문학 표현·가사 검색**까지 넓히고, 동시에 뜻 검증과 회귀 테스트를 강화해 검색 커버리지와 신뢰도를 함께 높였다.

## 신조어·줄임말·복수 표현 검색 보강

`Search UX` · `Slang` · `Segmentation` · `Japanese Learning`

실제 검색 과정에서 나타난 신조어·줄임말과 붙여 쓴 복수 표현의 누락 문제를 보완했다.

### 신조어·MZ 표현 데이터 확장
- `うっせぇ`, `わかんねぇ`, `すげぇ`, `やべぇ`, `それな`, `推し`, `沼る`, `メロい`, `草`, `りょ` 등 인터넷·팬덤·젊은 층 구어 표현을 별도 사전으로 추가했다.
- `うっせぇ ← うるさい`처럼 원형에서 음이 줄거나 거칠게 변한 표현은 파생 관계와 함께 관리하도록 구성했다.
- 신조어 후보는 일반 사전의 우연한 동음이의어보다 우선하도록 신뢰도·인기도 점수를 별도로 부여했다.
- `ばっか / ばっかり / ばかり`처럼 실제 회화에서 자주 축약되는 표현도 추가했다.

### 표현 쪼개보기 뜻 보강
- 기존에는 미리 뜻이 입력된 일부 조사·단어만 분절 의미가 표시되는 문제가 있었다.
- 각 조각마다 **기존 의미 데이터 → 문법/조사 뜻 → 사전 의미 → 일본어 직접 의미 검증** 순서로 뜻을 채우도록 수정했다.
- 복수 단어·문장 검색에서도 각 조각의 일본어 표기, 읽기, 한글 발음, 한국어 뜻을 개별적으로 유지하도록 개선했다.

### 복수 표현 검색
- 공백, `/`, `|`, 쉼표로 나눈 여러 표현을 각각 독립적으로 검색한 뒤 결과를 `/` 구분으로 보여주도록 추가했다.
- 띄어쓰기 없이 붙여 입력한 경우에도 자주 쓰는 표현·조사·줄임말의 발음 경계를 찾아 자동 분리하도록 확장했다.
- 예: `우소밧카`처럼 붙여 쓴 입력도 `嘘 / ばっか`처럼 분리 후보를 만들 수 있도록 처리했다.
- 단어를 억지로 하나의 문장이나 희귀 사전 항목으로 해석하기보다, 여러 표현으로 자연스럽게 분해되는 경우 분리 검색을 우선한다.

### 품질 관리
- 신조어 사전, 분절 의미 보강, 붙여쓰기 복원, 복수 표현 `/` 출력 규칙을 회귀 테스트에 추가했다.
- 검색 기능 수정 시 기존 구어체·문어체·J-POP·기초 어휘 검색과 함께 자동 검증되도록 유지했다.
