## HTML 기초 — 시맨틱 구조와 폼 요소 학습

`Frontend Study` · `HTML` · `UX/UI` · `Accessibility`

프로덕트 디자인과 프론트엔드 협업에 필요한 HTML 기초 구조를 학습하고, 간단한 예제를 직접 작성했다.

### 학습 내용
- HTML이 화면의 구조와 의미를 정의하고 CSS가 크기·색상·간격 등 시각적 표현을 담당한다는 역할 구분
- `main`, `section`, `article`, `h1`~`h3`, `p` 등 시맨틱 태그를 활용한 정보 구조 작성
- 페이지 이동에는 `a`, 현재 화면의 동작 실행에는 `button`을 사용하는 기준
- `href`, `class`, `type`, `id`, `for` 등 HTML 속성의 기본 역할
- `label`과 `input`을 `for`·`id`로 연결하는 방법
- 검색·이메일·일반 텍스트 등 입력 목적에 맞는 `input type` 구분
- `form`과 `button type="submit"`을 이용해 입력과 제출을 하나의 기능으로 구성

### 협업 관점
- 디자인 레이어명을 모양보다 `Page Title`, `Section Title`, `Save Button`처럼 역할 중심으로 지정하면 구현 구조를 전달하기 쉽다.
- 입력창 설계 시 라벨과 플레이스홀더의 역할을 구분하고 기본·포커스·오류·비활성 등 상태를 함께 정의해야 한다.
- HTML 태그와 속성은 영단어 자체를 암기하기보다 반복되는 역할과 연결 구조를 중심으로 익힌다.

### 정리

화면의 시각적 형태뿐 아니라 요소의 의미와 동작을 구분해 HTML 구조로 옮기는 기초를 익혔다. 링크·버튼과 입력 요소의 역할을 구분하고, 접근성과 개발 협업에 필요한 구조를 직접 작성했다.
