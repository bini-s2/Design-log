## 00:15 · 일본어 사운드→문자 학습 서비스 컨셉 정의

`Product Design` · `UX/UI` · `AI` · `Japanese Learning`

애니·J-POP 등으로 일본어를 오래 접해 **소리와 의미는 익숙하지만 한자·가타카나 표기에서 막히는 학습자**를 위한 제품 아이디어를 구체화했다. 기존 커리큘럼형 학습보다 사용자가 이미 알고 있거나 궁금해한 표현에서 학습이 시작되는 구조를 핵심으로 잡았다.

### Core Flow

- 한글로 기억하는 일본어 발음을 입력하면 가능한 일본어 원문 표기, 읽기, 뜻, 표현 구조를 연결한다.
- 한국어로 말하고 싶은 문장을 입력하면 자연스러운 일본어와 비슷한 표현·뉘앙스를 탐색할 수 있게 한다.
- Listening Mode에서는 실제로 들은 소리를 바탕으로 **문자 맞히기 → 뜻 맞히기**의 2단계 문제를 제공한다.
- 오답 시 강제로 반복시키지 않고 `다시 해보기 / 다음으로`를 선택하게 해 학습 부담을 낮춘다.
- 사용자가 자주 헷갈리는 한자·가타카나·표현을 기록해 개인화 복습으로 연결한다.

### Product Direction

- 학습 루프: `Sound → Script → Meaning → Recall`
- 표현마다 `일상 회화`, `가사에서 자주 보임`, `문어체` 같은 사용 맥락을 정성적 라벨로 제공하고, 향후 실제 사용 데이터 기반 빈도 정보로 확장한다.
- 소복이네 캐릭터 IP를 온보딩·피드백·복습 가이드에 활용하되 UI 자체는 학습에 집중할 수 있게 정돈한다.
- J-POP/영상 기반 기능은 저작권을 고려해 공식 링크·허용된 자료를 중심으로 설계하고, 초기 프로토타입은 자체 예문으로 학습 구조를 먼저 검증한다.
- 장기적으로 포트폴리오용 토이 프로젝트가 아니라 실제 판매 가능한 서비스/SaaS 가능성을 검토한다.

### MVP

부트캠프 시작 전에는 모든 기능을 구현하기보다 `한글 발음 입력 → 일본어 표기/뜻/읽기/표현 분석 → 저장`의 핵심 루프를 먼저 작동시키고, 직접 사용하면서 다음 기능을 결정한다.
