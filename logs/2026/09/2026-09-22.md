## Japanese Sound to Script — 검색 엔진 개선

오늘은 Sound to Script의 핵심 기능인 **한글 발음 → 일본어 표기 검색** 정확도를 집중적으로 개선했다.

### 작업 내용
- Vercel 배포 환경을 정리하고 GitHub `main` 푸시 시 자동 배포되도록 연결
- 기존 소수 하드코딩 데이터 중심 검색에서 **일본어 사전 기반 검색**으로 확장
- 한글 발음을 로마자로 변환한 뒤 일본어 읽기와 비교하는 검색 로직 추가
- 완전 일치 / 앞부분 일치 / 포함 일치보다 **발음 유사도와 길이 차이**를 함께 반영하도록 랭킹 개선
- 짧은 입력이 긴 고유명사·복합어로 잘못 매칭되는 문제 보정
- 대명사 + 조사처럼 사전 단일 항목으로 잡히지 않는 짧은 구문을 별도 인식
- 붙여 쓴 입력도 **단어 + 조사 + 동사/형용사 경계**를 복원해 검색하도록 개선
- 띄어쓰기 유무와 상관없이 긴 입력은 문장/구 후보도 함께 생성
- 장음, 촉음, 유사 자음 등 사용자가 잘못 들은 발음을 보정해 후보 추천
- 이상한 IME 조합, 노래 제목·소설명·고유명사 등 학습 의도와 먼 사전 항목은 우선순위 하향 또는 제외
- 후보 화면을 **가장 유사한 결과 순서**로 정렬하고, 보정된 결과는 별도 라벨로 구분
- 일본어 원문과 읽기뿐 아니라 **한글 발음 표기**도 함께 제공
- 결과 의미는 사전 메타 정보보다 자연스러운 한국어 뜻을 우선하도록 보완

### 현재 검색 흐름
`한글로 들린 소리 입력 → 발음 정규화/보정 → 띄어쓰기·문법 단위 복원 → 사전/구문 후보 생성 → 유사도 재정렬 → 일본어 표기 + 읽기 + 한글 발음 + 뜻`

단순 사전 검색보다, **정확한 철자를 모르는 상태에서 기억나는 소리만으로도 원하는 일본어 표현에 접근하는 경험**에 더 가까워졌다.
