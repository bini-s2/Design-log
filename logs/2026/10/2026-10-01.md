# 2026-10-01

## 17:45 · UX/UI 기초 개념 학습 정리

`UX/UI` · `Design System` · `Responsive Design` · `Study`

디스플레이·해상도부터 프레임 리사이징, 컨스트레인트, 디자인 시스템 구성 요소까지 UI 설계의 기초 개념을 학습하고 실습으로 확인했다.

### 학습 범위
- 해상도는 가로 픽셀 수 × 세로 픽셀 수로 표현되며, 화면 크기와 해상도는 별개의 개념임을 정리
- 기준 화면 크기에서 UI를 설계한 뒤 반응형 규칙으로 다양한 디바이스 크기에 대응하는 방식 이해
- 1x 논리 좌표와 @2x·@3x 픽셀 배율, 실제 물리 픽셀 렌더링의 차이 정리
- Fixed / Fill / Hug(Fit Content)의 리사이징 원리 비교
- Constraint의 Top / Bottom / Top & Bottom / Center / Scale 동작 원리 실습
- Auto Layout의 Fill과 일반 프레임의 Top & Bottom Constraint가 비슷한 결과를 만드는 차이 확인
- Relative / Absolute / Fixed / Sticky 포지션의 기준과 레이아웃 흐름 차이 정리
- Foundation, Design Token, Component의 관계와 Color / Spacing / Radius / Elevation 개념 학습
- Filled / Outline / Ghost / Split Button의 차이와 버튼 컴포넌트 내부 구조 확인
- Label / Placeholder / Helper Text / Validation / Error Text의 역할 구분

### 기술적 정리
- Top & Bottom Constraint는 자식의 크기를 고정하는 대신 부모와의 위·아래 간격을 유지하기 때문에 부모가 리사이즈될 때 자식 높이가 함께 변한다.
- Fill은 Auto Layout 안에서 사용 가능한 남은 공간을 채우는 방식이며, Constraint와 목적은 비슷해 보여도 작동 원리는 다르다.
- Absolute는 부모 자체를 무시하는 것이 아니라 일반 레이아웃 흐름에서 빠진 뒤 기준 부모를 중심으로 위치를 지정한다.
- 디자인 토큰은 컴포넌트가 아니라 반복 사용하는 디자인 값을 의미하며, 컴포넌트는 해당 토큰을 조합해 구성한다.
- Validation은 입력값을 조건과 비교하는 검증 로직이며, Helper/Error Text는 그 조건이나 결과를 사용자에게 보여주는 표현 요소다.
