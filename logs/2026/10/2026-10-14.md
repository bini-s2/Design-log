# 2026-10-14 — 개인 학습 웹의 브랜드·검색 UX 고도화

**분야:** BX / Product Design / UI·UX / Web / AI-assisted Design

## Overview

개인 외국어 학습 웹 프로젝트의 작업 과정을 **와이어프레임 → 기능 구현 → 브랜드·제품 고도화**의 세 단계로 정리했다. 두 이전 단계는 과거 작업물의 회고 구분이며, 당시 정식 릴리스로 배포했다는 의미는 아니다.

## 시각 디자인과 UX

- 워드마크의 표기·색상 역할을 확정하고, 기존 문자 기반 헤더 로고를 디자이너 제작 에셋으로 교체했다. 데스크톱과 모바일 크기를 각각 조정했다.
- Hero와 두 단계의 제목, 본문을 나눠 **서체 역할을 정의**했다. 디자인 가이드 확정과 실제 웹폰트 구현은 다른 진행 상태로 관리했다.
- 홈 제목 위에 중복된 보조 라벨을 삭제하고 검색 결과·표현 상세 화면의 카드 구조와 정보 위계를 통일했다.
- 설명이 반복되는 영역은 줄이고 원문·읽기·발음·뜻·저장/학습 행동을 우선 노출하도록 정리했다.
- 화면 전환을 브라우저 뒤로가기·앞으로가기와 연결하고 검색·학습 상태가 보존되도록 개선했다.

## 검색 품질과 안정성

- 외래어의 **발음과 실제 한국어 뜻**이 혼동되는 사례, 부정형 활용 누락, 긴 검색어에 불필요한 단어가 덧붙는 문제를 검수했다.
- 전체 문장을 입력했을 때 명사 뜻을 놓치고 비슷한 가타카나로 바꾸던 사례를 수정했다. 검증된 명사·동사 조합만 사용하고, 실제로 들리지 않은 조사를 원문에 임의로 삽입하지 않는 방식이다.
- 사전·자동완성·변환 API에서 중복 요청을 공유하고 짧게 캐시해 네트워크 낭비를 줄였다. 요청 시간 제한과 지연 안내를 추가했다.
- 검색·화면 회귀 검사와 대표 검색 표현 QA를 보강했다. 자동 테스트가 포함된 배포 빌드는 성공했지만, **운영 환경의 실제 검색 속도와 정확도 향상 폭은 아직 직접 측정하지 못했다.**

## 기록 구조 변경

제품 변화가 클 때만 새로운 버전을 만들고, 작은 디자인 수정·검색 오류는 같은 버전의 작업 로그에 누적하는 기준을 정했다. 단계별 목표·작업·검증·남은 과제를 버전별 문서로 분리하되, 실제 Git 커밋/배포와 문서상 버전을 혼동하지 않도록 했다.

## 배운 점과 남은 과제

검색형 학습 서비스는 후보를 많이 만드는 것보다 **입력 전체의 발음을 정확하게 복원하고 문맥에 맞는 의미를 보여주는지**가 중요했다. 디자인도 검색 결과 화면에서 끝나지 않고 후보 선택, 학습, 저장까지 이어지는 흐름을 함께 살펴봐야 했다.

다음은 반응형 타이포그래피의 실제 적용·시각 검수와 운영 환경 검색 시간 측정이 필요하다.

> 공개용 작업 기록이므로 개인 사연, 상세 내부 자료, 프로젝트 식별 정보는 제외했다.
